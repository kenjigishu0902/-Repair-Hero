# Repair Hero

フェニちゃんを操作して「スマホ修理商店街」を走り抜ける、オリジナルの 2D 横スクロールアクションゲームです。Canvas と `requestAnimationFrame` のみで動作し、ビルドや外部ライブラリは必要ありません。

## 遊び方

```sh
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開き、タイトル画面の「ゲームスタート」を選んでください。

| 操作 | キーボード | タッチ |
|---|---|---|
| 左移動 | `A` / `←` | 左下 `◀` |
| 右移動 | `D` / `→` | 左下 `▶` |
| ジャンプ／二段ジャンプ | `Space` | 右下中央 `JUMP` |
| 左右ダッシュ | `Shift`＋進行方向 | 左下・移動ボタンの真上 `DASH ←` / `DASH →` |
| 水中／KING上下移動 | `W` / `↑`、`S` / `↓` | 左下 `↑` / `↓`（該当時のみ表示） |
| 足場を降りる | `S` / `↓` | 左下中央 `↓ DROP / DIVE` |
| スタミナ任意回復 | `C` | 右下 `⚡ STAMINA CHARGE` |
| フェニックス翼攻撃 | `Z` | 右下 `🪽 PHOENIX WING` |
| 剣／ラッシュパンチ | `X` | 右下 `ATTACK` / `RUSH PUNCH` |
| ポーズ | `Escape` | 右上 `Ⅱ` |

薄い足場では下入力でそのまま下へ降りられます。専用 `CHARGE` を長押しすると、安全な足場上（水中／KING は停止中）でダッシュ用スタミナを任意に高速回復できます。従来の地上 `↓` 長押し回復も互換操作として残しています。コイン速度は 0〜4 枚が通常、5〜9 枚が中速、10 枚以上が高速の3段階です。5枚目と10枚目には専用表示・風／残像・SEが入ります。

## ステージ 1-1〜2-5

既存の「スマホ修理商店街」を 1-1 として残し、地下ケーブル迷宮、クラウド空中回廊、キング基板・決戦、本格地下迷宮、深海リペア海域、迫る圧壊壁へ連続して進みます。1-5 の最奥には「MEGA BUG TITAN」、2-5 の最奥には水中大型ボス「ABYSS MECHA SHARK」が待っています。どちらも撃破演出が終わるまでゴールは開きません。

### 1-1「スマホ修理商店街」

- 穴、段差、固定足場、移動足場を備えた全長 10,600px のステージ
- 遠景ビルと修理店街の 2 層パララックス背景
- スマホ戦闘ロボ、工具メカ、暴走バッテリーロボなど、ステージテーマ別のメカ敵
- 敵を上から踏むと撃破、横から接触または水滴に当たると 1 ダメージ
- HP 3、ダメージ後の無敵時間、コイン、スコア、制限時間
- 中間チェックポイント、落下復帰、ゲームオーバー、ゴール、クリア、リトライ、タイトル復帰

フェニちゃんは専用画像で描画され、速度に連動した上下動・前傾・砂煙で走行を表現します。5モードそれぞれに16フレームの `feni_motion_*.png` を追加し、呼吸・瞬き・左右確認・足踏み・警戒・伸び、踏み切り・上昇・落下・着地、二段ジャンプ、翼攻撃を状態管理します。操作が入ると特殊Idleを即座に中断します。ダッシュには残像と画面揺れ、二段ジャンプには専用回転・翼・火花・効果音、着地には砂煙と軽い画面揺れが入ります。

`PHOENIX WING` は剣とは独立したフェニちゃん固有攻撃です。構えから翼を広げ、炎をまとった羽根型エネルギーを前方へ発射します。射程620〜700px、再使用約0.95秒、通常敵へ1撃、ボスへ0.75ダメージで、剣・踏みつけ・ラッシュパンチの役割を残しています。

## 4 種類の変身モード

安全な空中地点へ浮遊するモード別アイテムを取ると変身します。バッテリーは 25 秒間、被ダメージとノックバックを軽減し、被弾後に HP を徐々に回復します。液晶は 25 秒間、通常の約 1.42 倍で移動し、2 枚の青いシールドが最初の 2 回のダメージを無効化します。キングは 20 秒間、上下左右へ高速飛行できる完全無敵状態となり、通常敵を接触撃破し、ボスへ接触ダメージを与えます。ゴリマッチョは 25 秒間 `RUSH PUNCH` が使用でき、被弾ごとに最大 HP の半分を失います。

全モードに実ファイルの状態別スプライト（`feni_states_*.png`）を追加し、専用ダッシュ表情、剣の構え／振り払い表情、笑顔のゴールポーズ、復活表情を描画します。ゴール時の台詞はモード別に切り替わり、復活時は「何度でも蘇る！！」を表情画像付きの白い吹き出しで表示します。

## 動作仕様

ゲームループはページにつき 1 本だけ生成され、移動や物理演算は delta time ベースです。ダッシュ姿勢は接地／空中状態より優先する短いアクションロックで保持し、毎フレームの画像切替による乱れを防ぎます。液晶モードでも敵・BGM・タイマーは通常速度のままで、高速移動は細分化した衝突判定を通ります。リトライ時はプレイヤー、敵、弾、コイン、足場、チェックポイント、時間、カメラをすべて初期化します。Canvas は `resize`、`orientationchange`、`visualViewport`、縦横画面、最大 2 倍の `devicePixelRatio` に対応しています。縦画面では CSS 縮小ではなく実際のカメラ viewport を広げ、先読み範囲を確保します。タッチボタンは Pointer Events を利用し、ダッシュとジャンプを含む複数指の同時押しに対応します。

## SECTION 制ステージと決戦

全ステージは SECTION 制の攻略単位に再設計されています。床区間と中間足場を広げ、穴・危険物・崩れる床を少し減らし、警告ストライプ付きの穴、横・縦移動足場、落下物、敵弾、トゲ／電撃を組み合わせています。各 SECTION の直後には安全床上のチェックポイントがあります。トゲは赤い大型形状と警告パネル、電撃は青白い点滅として表示します。敵は大型のメカ画像と広い踏みつけ判定帯を使います。機種ごとに2種類の攻撃を交互に選び、発光・照準線・約0.8〜0.9秒の予告、約6秒の通常射撃、約8秒の特殊攻撃で使用します。敵弾は種類別に最大360〜620px、約2.2〜3.2秒で消え、画面外でも即時破棄されます。全敵共通の発射ロックにより回避不能な同時弾幕を抑えています。

1-5 の最終 SECTION は「MEGA BUG TITAN」とのボス戦です。手前のフェニックス剣（`phoenix_sword.png`）を取得すると `X` または右側の `⚔ ATTACK` で斬れます。通常フェニちゃんは剣取得後に構え姿へ変わり、攻撃時は `feni_sword_ready.png` → `feni_sword_swing.png` → `feni_sword_finish.png` の炎付き3フレームで斬撃します。ボスの頭へ上から着地してもダメージを与えられます。ゴリマッチョ中の `RUSH PUNCH` は横パンチ画像、連続拳残像、炎・火花・稲妻・画面シェイク・ヒットストップと、画面幅約 72% の貫通衝撃波を組み合わせ、遠距離の敵・壊せる壁・ボスへ命中します。

両ボス戦は幅2,300px以上の専用アリーナです。進入時に雑魚・雑魚弾を消去し、ゲート封鎖、カメラ調整、警告、ボスBGM、1.8秒の安全な登場時間を経てAIが開始します。ボスは距離を保ちながら追跡し、全技が「予兆 → 攻撃 → 硬直」で進みます。Titanは突進・射撃・ジャンプ・地面叩き・薙ぎ払い・咆哮・マグマ、Sharkは噛みつき・魚雷・飛び出し・潜航落下・水弾扇・渦攻撃を段階的に使用します。HP60%未満で第2形態、30%未満で最終形態へ移行し、撃破演出が終わるまでゴールはロックされます。

1-6「地下迷宮」は深度の異なる長大な区画、縦移動足場、壊せる壁、危険物、分岐足場、隠し報酬に加え、地上側を横断できる陸上ルートと地下へ戻る連絡足場を備えます。1-7「深海リペア海域」は上下左右へ泳ぐ専用物理、水流、狭い洞窟、泡による酸素回復、OXYGEN ゲージを備えます。海中では `JUMP` が上昇、専用の `↓` が潜水になり、左右ダッシュも使用できます。両ステージに複数のチェックポイントがあり、海中での復帰時は酸素も全回復します。

2-5「深海メカシャーク決戦」では通常の海中ギミックを抑えた広い決戦区画で「ABYSS MECHA SHARK」と戦います。フェニックス剣はボスゲートより 600px 以上手前に配置され、剣を持って戦闘へ入ると専用台詞を表示します。

1-8「圧壊ウォール・エスケープ」は後方の巨大壁が序盤・中盤・終盤で段階的に加速する強制スクロールステージです。壁が主な脅威になるよう通常トラップは抑え、ダッシュで破壊できる障害物と明確な走行ラインを中心に構成しています。

縦画面では主人公の見た目を画面高の約 14〜17%に保ち、最小 470px 相当の横方向視界と進行方向の先読みを確保する専用カメラを使用します。横画面も 1,150px 相当まで引き、高速移動時は先読み量を増やし、ボス戦では実 viewport を自動調整します。320px 幅を含む縦画面では移動／左右ダッシュ／上下／専用 CHARGE／ジャンプ／攻撃が重ならない2列操作として表示します。KING／水中では上下矢印を青白く強調します。Pointer Events による複数指入力のため、移動・ダッシュ・ジャンプ・攻撃を組み合わせられます。
