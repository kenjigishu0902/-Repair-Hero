# Repair Hero

フェニちゃんを操作して「スマホ修理商店街」を走り抜ける、オリジナルの 2D 横スクロールアクションゲームです。Canvas と `requestAnimationFrame` のみで動作し、ビルドや外部ライブラリは必要ありません。

## 遊び方

```sh
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開き、タイトル画面の「ゲームスタート」を選んでください。ステージは通常プレイで約 1〜2 分です。

| 操作 | キーボード | タッチ |
|---|---|---|
| 左移動 | `A` / `←` | 左下 `◀` |
| 右移動 | `D` / `→` | 左下 `▶` |
| ジャンプ | `Space` | 右下 `JUMP` |
| ダッシュ | `Shift` | 右下 `DASH` |
| ポーズ | `Escape` | 右上 `Ⅱ` |

## ステージ 1「スマホ修理商店街」

- 穴、段差、固定足場、3 基の移動足場を備えた全長 7,600px のステージ
- 遠景ビルと修理店街の 2 層パララックス背景
- 「割れスマホ」「バッテリーお化け」「水没スマホ」の 3 種類の敵
- 敵を上から踏むと撃破、横から接触または水滴に当たると 1 ダメージ
- HP 3、ダメージ後の無敵時間、コイン、スコア、制限時間
- 中間チェックポイント、落下復帰、ゲームオーバー、ゴール、クリア、リトライ、タイトル復帰

フェニちゃんは速度に連動して手足を振り、上下動・前傾・砂煙で歩行と走行を表現します。ジャンプ上昇時は縦長、落下時は横長に変形し、着地時には砂煙と軽い画面揺れが入ります。

## 動作仕様

ゲームループはページにつき 1 本だけ生成され、移動や物理演算は delta time ベースです。リトライ時はプレイヤー、敵、弾、コイン、足場、チェックポイント、時間、カメラをすべて初期化します。Canvas はリサイズ、縦横画面、最大 2 倍の `devicePixelRatio` に対応しています。タッチボタンは Pointer Events を利用し、複数指の同時押しと押下中の継続入力に対応します。
