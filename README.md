# Repair Hero

フェニちゃんを操作して「スマホ修理商店街」を走り抜ける、オリジナルの 2D 横スクロールアクションゲームです。Canvas と `requestAnimationFrame` のみで動作し、ビルドや外部ライブラリは必要ありません。

## 遊び方

```sh
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開き、タイトル画面の「ゲームスタート」を選んでください。ステージは通常プレイで約 1〜2 分です。

| 操作 | キーボード | タッチ |
|---|---|---|
| 左移動 | `A` / `←` | 左下 `◀` |
| 右移動 | `D` / `→` | 左下 `▶` |
| ジャンプ／二段ジャンプ | `Space` | 右下中央 `JUMP` |
| 左右ダッシュ | `Shift`＋進行方向 | 左下・移動ボタンの真上 `DASH ←` / `DASH →` |
| ポーズ | `Escape` | 右上 `Ⅱ` |

## ステージ 1-1〜1-5

既存の「スマホ修理商店街」を 1-1 として残し、地下ケーブル迷宮、水没スマホ海域、クラウド空中回廊、キング基板・決戦へ連続して進みます。1-5 の最奥には HP ゲージ付きの大型ボス「MEGA BUG」が待っています。

### 1-1「スマホ修理商店街」

- 穴、段差、固定足場、3 基の移動足場を備えた全長 7,600px のステージ
- 遠景ビルと修理店街の 2 層パララックス背景
- 「割れスマホ」「バッテリーお化け」「水没スマホ」の 3 種類の敵
- 敵を上から踏むと撃破、横から接触または水滴に当たると 1 ダメージ
- HP 3、ダメージ後の無敵時間、コイン、スコア、制限時間
- 中間チェックポイント、落下復帰、ゲームオーバー、ゴール、クリア、リトライ、タイトル復帰

フェニちゃんは専用画像で描画され、速度に連動した上下動・前傾・砂煙で走行を表現します。ダッシュには残像と画面揺れ、二段ジャンプには回転・火花・専用効果音、着地には砂煙と軽い画面揺れが入ります。

## ランダム変身モード

ステージに点在する紫色の「？」アイテムを取ると、10 秒間バッテリー・液晶・キングのいずれかへランダム変身します。バッテリーは被ダメージを半減し、ダメージ後 1 秒待つと少しずつ HP を自動回復します。液晶は通常速度約 2.4 倍、ダッシュ約 3 倍、空中加速強化、獲得スコア 2 倍の超高速モードです。キングは完全無敵で、敵や敵弾を無効化し、接触攻撃と JUMP 長押しによる自由飛行が可能です。

## 動作仕様

ゲームループはページにつき 1 本だけ生成され、移動や物理演算は delta time ベースです。液晶モードでも敵・BGM・タイマーは通常速度のままで、高速移動は細分化した衝突判定を通ります。リトライ時はプレイヤー、敵、弾、コイン、足場、チェックポイント、時間、カメラをすべて初期化します。Canvas は `resize`、`orientationchange`、`visualViewport`、縦横画面、最大 2 倍の `devicePixelRatio` に対応しています。縦画面は専用の接写・先読みカメラです。タッチボタンは Pointer Events を利用し、ダッシュとジャンプを含む複数指の同時押しに対応します。
