# Repair Hero

スマホ修理屋を舞台にした、レスポンシブ対応の横スクロール 2D アクションゲームです。フェニちゃんを操作し、壊れた端末モンスターを修理工具で倒して全 6 ステージのクリアを目指します。

## プレイ方法

ビルドや外部ライブラリは不要です。`index.html` をブラウザで開くか、そのまま GitHub Pages で公開できます。

```sh
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開いてください。

## 操作

| 操作 | キーボード | タッチ |
|---|---|---|
| 移動 / しゃがみ | `A` `D` `S` または矢印キー | 左下ボタン |
| ジャンプ / 二段ジャンプ / 壁ジャンプ | `Space` | `JUMP` |
| 攻撃（4 種の工具を切替） | `Z` / `J` | `攻撃` |
| ダッシュ | `X` / `K` / `Shift` | `DASH` |
| Repair Burst | `C` / `L` | `必殺` |
| ポーズ | `Escape` | 右上の `Ⅱ` |

タイトル画面から設定、ローカルランキング、敵図鑑を閲覧できます。BGM と効果音は Web Audio API で生成され、初回操作後に再生されます。
