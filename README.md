# Repair Hero

フェニちゃんを操作して「スマホ修理商店街」を走り抜ける、オリジナルの 2D 横スクロールアクションゲームです。Canvas と `requestAnimationFrame` のみで動作し、ビルドや外部ライブラリは必要ありません。

## 遊び方

```sh
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開き、タイトル画面の「ゲームスタート」を選んでください。

| 操作 | キーボード | タッチ |
|---|---|---|
| 左移動 | `A` / `←` | 左下 `◀` |
| 右移動 | `D` / `→` | 左下 `▶` |
| ジャンプ／二段ジャンプ | `Space` | 右下 `⬆ ジャンプ` |
| 左右ダッシュ | `Q` / `E`（または `Shift`＋進行方向） | 左下 `⚡← 左ダッシュ` / `→⚡ 右ダッシュ` |
| 水中／KING上下移動 | `W` / `↑`、`S` / `↓` | 左下 `▲ うえ` / `▼ 潜る`（該当時のみ表示） |
| 伏せる／足場を降りる | `S` / `↓` | 左下中央 `▼ しゃがむ／降りる` |
| フェニックス翼攻撃 | `Z` / `K` | 右下 `🪽 つばさ攻撃` |
| 剣／ラッシュパンチ | `X` / `J` | 右下 `⚔ 剣攻撃` / `👊 ラッシュパンチ` |
| モード必殺技 | `C` / `V` / `L` | 右下 `💥 ひっさつ`（モード別表示） |
| ポーズ | `Escape` | 右上 `Ⅱ` |

薄い足場では下入力でそのまま下へ降り、通常の床では全モード固有の見た目を保ったまま伏せます。伏せ中は当たり判定も低くなり、予告付きスキャンレーザーや敵弾を回避できます。専用のチャージボタンは撤去し、ダッシュスタミナは操作を離すと自動回復します。満タンから連続ダッシュできる時間は従来の約2.6秒から約3.6秒へ延長しています。コイン速度は 0〜4 枚が通常、5〜9 枚が中速、10 枚以上が高速の3段階です。5枚目と10枚目には専用表示・風／残像・SEが入ります。

## ステージ 1-1〜3-1

既存の「スマホ修理商店街」を 1-1 として残し、地下ケーブル迷宮、クラウド空中回廊、キング基板・決戦、本格地下迷宮、深海リペア海域、迫る圧壊壁、機鋼ジャングル、終焉回路へ連続して進みます。1-5 の「MEGA BUG TITAN」、2-5 の「ABYSS MECHA SHARK」、2-6 の「JUNGLE MECHA GORILLA」、3-1 の「DARK FENI-CHAN」を撃破するまで各決戦ステージのゴールは開きません。全11ステージに専用BGMを割り当て、各ボスには通常／強化形態の専用戦闘曲を用意しています。

### 1-1「スマホ修理商店街」

- 穴、段差、固定足場、移動足場を備えた全長 10,600px のステージ
- 夕景・遠景ビル・近景ビル・ネオン配線・店舗を重ねた多層パララックス背景
- 道頓堀の運河・橋・ネオン、通天閣と新世界、大阪城と堀、あべのハルカス、梅田スカイビル、岸和田城とだんじりをステージごとに描き分けた大阪ランドマーク
- スマホ戦闘ロボ、工具メカ、暴走バッテリーロボなど、ステージテーマ別のメカ敵
- 敵を上から踏むと撃破、横から接触または水滴に当たると 1 ダメージ
- HP 3、ダメージ後の無敵時間、コイン、スコア、制限時間
- 中間チェックポイント、落下復帰、ゲームオーバー、ゴール、クリア、リトライ、タイトル復帰

フェニちゃんは専用画像で描画され、速度に連動した上下動・前傾・砂煙で走行を表現します。5モードそれぞれの16フレーム `feni_motion_*.png` から、呼吸、低頻度の欠伸／大きな背伸び、踏み切り・上昇・落下・着地、二段ジャンプ、翼攻撃を状態管理します。従来のランダムな顔・視線切替は外し、操作が入ると欠伸／背伸びを即座に中断します。歩行は左右の足運びを滑らかにクロスフェードする4拍サイクルです。剣は歩行・ダッシュ・上昇・落下・着地ごとに計測した手のアンカーへ追従し、空中で浮いて見えないようにしています。ダッシュSEは一度だけ鳴るメカニカルな加速音です。

通常ルートでは安全な床へ紫のワープゲートがランダム出現します。飛び込むと16秒の独立したボーナスステージへ移動し、30枚のコインを回収して帰還できます。ボーナス中は元ステージの敵・ボス・残り時間を停止し、帰還時は元の安全な位置・カメラ・BGMへ復元します。消滅・再出現間隔とオブジェクト数を固定し、スマホでゲートやコインが蓄積しない構造です。

`PHOENIX WING` は剣とは独立したフェニちゃん固有攻撃です。構えから翼を広げ、炎をまとった羽根型エネルギーを前方へ発射します。射程620〜700px、再使用約0.95秒、通常敵へ1撃、ボスへ0.75ダメージで、剣・踏みつけ・ラッシュパンチの役割を残しています。

## 4 種類の変身モード

安全な空中地点へ浮遊するモード別アイテムを取ると変身します。バッテリーは 25 秒間、被ダメージとノックバックを軽減し、待ち時間なしで HP を常時回復します。液晶は 25 秒間、通常の約 1.42 倍で移動し、5 枚の青いシールドが最初の 5 回のダメージを無効化します。キングは 20 秒間、上下左右へ高速飛行できる完全無敵状態となり、通常敵を接触撃破し、ボスへ接触ダメージを与えます。ゴリマッチョは 25 秒間 `RUSH PUNCH` が使用でき、被弾ごとに最大 HP の半分を失います。

`SPECIAL`／`C`／`V`／`L` ではモード固有の必殺技を発動します。必ず「高速全画面カットイン → 読みやすい表情付き台詞 → 技発動」の順に進みます。カットインは斜め斬光・瞬間フラッシュ・モード別カラー・大判ポートレートを約0.42秒に凝縮し、台詞込みでも約1.6秒で攻撃へ移ります。NORMAL は敵を追尾する炎の羽を大量発射、BATTERY は通常敵 1 体を味方化して自律攻撃、LCD は安全な着地点を再検証しながら最大 6 体へ連続瞬間移動攻撃、GORI MACHO は 18 方向へ貫通ラッシュパンチ、KING は先行して自律戦闘する分身 2 体を出します。空中で発動した場合はカットインと台詞の間だけ高度を安全に保持し、攻撃開始時に重力と上下速度を復元するため、その場から必殺技へ自然につながります。各技には指定の吹き出し台詞、専用モーション、SE、発光、残像、画面効果があり、変身中の必殺技は 1 回、NORMAL はクールタイム後に再使用できます。

全モードに実ファイルの状態別スプライト（`feni_states_*.png`）を追加し、専用ダッシュ表情、剣の構え／振り払い表情、笑顔のゴールポーズ、復活表情を描画します。ゴール時の台詞はモード別に切り替わり、復活時は「何度でも蘇る！！」を表情画像付きの白い吹き出しで表示します。

## 動作仕様

ゲームループはページにつき 1 本だけ生成され、移動や物理演算は delta time ベースです。ダッシュ姿勢は接地／空中状態より優先する短いアクションロックで保持し、毎フレームの画像切替による乱れを防ぎます。液晶モードでも敵・BGM・タイマーは通常速度のままで、高速移動は細分化した衝突判定を通ります。LCD必殺技・チェックポイント・落下復帰は共通の安全配置処理を通り、床・危険物・壁・ボスを再検証してから重力を再開するため、ステージ下へ落ち続けません。リトライ時はプレイヤー、敵、弾、コイン、足場、チェックポイント、時間、カメラをすべて初期化します。Canvas は `resize`、`orientationchange`、`visualViewport`、縦横画面に対応し、タッチ端末では表示サイズを変えずに内部解像度だけを最大1.5倍・約180万画素へ制限します。縦画面では CSS 縮小ではなく実際のカメラ viewport を広げ、先読み範囲を確保します。タッチボタンは Pointer Events を利用し、ダッシュとジャンプを含む複数指の同時押しに対応します。

スマホ向けには、背景のパララックス層を少数の描画へまとめ、画面外の足場・敵・弾・景観・エフェクトを描画しないカリングを追加しています。装飾粒子と弾プールも端末別に制限し、HUD更新を間引き、ボス形態変化時の全画面CSSフィルターと待機中ボタンの常時アニメーションを停止します。さらに変身素材はアイテムへ近づいた時、剣・ボス素材はアリーナへ近づいた時、通常敵の高精細メカPNGは該当する敵種が画面へ近づいた時だけ先読みします。全モード・全敵・ボス画像を一括展開しないため、Safariの起動時メモリと画像デコード負荷を抑えます。フレーム落ち時もゲーム時間が過度に遅れないよう更新幅を調整しています。

## SECTION 制ステージと決戦

全ステージは SECTION 制の攻略単位に再設計されています。床区間と中間足場を広げ、穴・危険物・崩れる床を少し減らし、警告ストライプ付きの穴、横・縦移動足場、落下物、敵弾、トゲ／電撃を組み合わせています。さらに高速で走り抜ける NITRO REPAIR RAIL、伏せ／ジャンプで避ける予告式 SCAN LASER、安全地点を結ぶ PHASE LINK、水中で上昇と酸素回復を行う O₂ JET を追加しています。各 SECTION の直後には安全床上のチェックポイントがあります。トゲは赤い大型形状と警告パネル、電撃は青白い点滅として表示します。通常敵は赤い発光コア、損傷装甲、工具・基板・バッテリー部品を持つ高精細なダークSFメカPNGへ復帰し、スマホ戦闘ロボ・工具メカ・バッテリーロボ・基板兵・ドリルメカ・メカシャーク・戦闘ドローンを描き分けます。広い踏みつけ判定帯と、軽量型は通常攻撃1回、装甲型は2回で撃破できるゲーム性は維持します。機種ごとに2種類の攻撃を交互に選び、発光・照準線・約0.8〜0.9秒の予告、約6秒の通常射撃、約8秒の特殊攻撃で使用します。敵弾は種類別に最大360〜620px、約2.2〜3.2秒で消え、画面外でも即時破棄されます。全敵共通の発射ロックにより回避不能な同時弾幕を抑えています。

1-5 の最終 SECTION は「MEGA BUG TITAN」とのボス戦です。手前のフェニックス剣（`phoenix_sword.png`）を取得すると `X`／`J` または右側の `⚔ ATTACK` で斬れます。静止構えと斬撃中は5モードそれぞれの両手持ち専用フレームを使い、移動・ジャンプ・ダッシュ中は折れていない正規の剣PNGを手元へ追従させます。斬撃には炎と遠距離斬撃波が付きます。剣、翼、火の羽、味方弾、ラッシュパンチ、各種衝撃波は敵弾・ボス弾・敵衝撃波と接触すると火花と専用SEを伴って相殺します。ボスの頭へ上から着地してもダメージを与えられます。ゴリマッチョ中の `RUSH PUNCH` は横パンチ画像、連続拳残像、炎・火花・稲妻・画面シェイク・ヒットストップと、画面幅約 72% の貫通衝撃波を組み合わせ、遠距離の敵・壊せる壁・ボスへ命中します。

ボス戦は横幅3,100px以上の専用アリーナです。陸上アリーナには6枚の一方向段差を置き、横ダッシュだけでなく上段へ逃げる立体回避ルートを確保しています。進入時に雑魚・雑魚弾を消去し、ゲート封鎖、カメラ調整、警告、ボスBGM、1.8秒以上の安全な登場時間を経てAIが開始します。ボスは距離を保ちながら追跡し、全技が「予兆 → 攻撃 → 硬直」で進みます。Titanは突進・射撃・ジャンプ・地面叩き・薙ぎ払い・咆哮・マグマ、Sharkは噛みつき・魚雷・飛び出し・潜航落下・水弾扇・渦攻撃を段階的に使用します。全ボスに必殺技ゲージがあり、満タンになると生成済みの専用WebPを使った高速全画面カットインと台詞を表示してから予兆へ移り、Titan は全方位過負荷と落下柱、Shark は深海津波・水刃・突進、Gorilla は連続地盤波と多段落下物、Dark Feni は形態別の複合必殺技を発動します。HP60%未満で第2形態、30%未満で最終形態へ移行し、撃破演出が終わるまでゴールはロックされます。

1-6「地下迷宮」は深度の異なる長大な区画、縦移動足場、壊せる壁、危険物、分岐足場、隠し報酬に加え、地上側を横断できる陸上ルートと地下へ戻る連絡足場を備えます。1-7「深海リペア海域」は上下左右へ泳ぐ専用物理、水流、狭い洞窟、泡による酸素回復、OXYGEN ゲージを備えます。海中ではフェニちゃんの身体と手前へ軽量Canvas描画の酸素ボンベ・固定ベルト・呼吸管・マスクを重ね、`JUMP` が上昇、専用の `↓` が潜水になり、左右ダッシュも使用できます。両ステージに複数のチェックポイントがあり、海中での復帰時は酸素も全回復します。

2-5「深海メカシャーク決戦」では通常の海中ギミックを抑えた広い決戦区画で「ABYSS MECHA SHARK」と戦います。フェニックス剣はボスゲートより 600px 以上手前に配置され、剣を持って戦闘へ入ると専用台詞を表示します。

2-6「機鋼ジャングル・獣王決戦」は、発光する機械樹、ケーブル蔦、遺跡端末、ホタル型ドローンを重ねたジャングルステージです。6本の実操作可能なツタは `▲` でつかみ、上下移動、左右の振り子運動、ジャンプでの飛び移りに対応します。最奥では巨大な `JUNGLE MECHA GORILLA` と3体の `GUARD MONKEY` が登場します。3体のメカ小猿が生きている間はゴリラの装甲へ一切ダメージが通らず、小猿を全滅させると `MINION SHIELD BREAK` が発生して攻撃可能になります。ゴリラは予告付きの突進、腕薙ぎ、スクラップ投擲、地面叩き、咆哮弾をフェーズごとに解禁します。

3-1「終焉回路・ダークフェニ決戦」は2-6クリア後に開く真の最終戦です。開始時は `IRREGULAR!!` の全面警告、暗転、終焉ステージ表示を行い、アリーナではダークフェニが「始まりの終わりを始めよう….」と告げてから戦闘を開始します。両者のHPは7で、4種類の変身アイテムを継続配置し、HPとダッシュを全回復するスタミナコーラが約14〜21秒で安全地点へ再出現します。

ダークフェニは既存フェニちゃんのシルエット・体型・各モード素材を維持しつつ、紫と深紅の身体、亀裂、黒炎、笑わない闇堕ち表情へ統一しています。キャラクター自身の右目には暗い深紅／紫の斜め傷があり、戦闘中の本体と基板モードの分身は向きが変わっても傷が同じ右目へ追従します。5形態すべてに透過WebPの専用全画面カットインと台詞を用意しています。黒翼ノーマルは羽根攻撃と「堕ちろ、混沌に」の時間制限付き追尾闇弾、漏電モードはダメージ軽減と全周電撃・電柱・地走り、液晶割れモードは高速移動と連続背後瞬間斬り、ゴリマッチョはラッシュと多段地盤投擲、基板モードは飛行・2体の攻撃分身・闇弾斉射を使用します。闇弾は1.65秒後に追尾を止め、最大930pxまたは3.8秒で必ず破棄されます。撃破後は「..それがお前の答えか..」の台詞、影へ流れて消える退場演出、専用曲のEND ROLL、TRUE ENDリザルトへ進みます。

1-8「圧壊ウォール・エスケープ」は後方の巨大壁が序盤・中盤・終盤で段階的に加速する強制スクロールステージです。壁が主な脅威になるよう通常トラップは抑え、ダッシュで破壊できる障害物と明確な走行ラインを中心に構成しています。

縦画面では主人公の見た目を画面高の約 14〜17%に保ち、最小 470px 相当の横方向視界と進行方向の先読みを確保する専用カメラを使用します。横画面も 1,150px 相当まで引き、高速移動時は先読み量を増やし、ボス戦では実 viewport を自動調整します。320px 幅を含む縦画面では左側の移動パッドと、右側3列の必殺技／翼／攻撃／ジャンプが重ならない専用配置へ切り替わります。KING／水中では上下矢印を青白く強調します。Pointer Events による複数指入力のため、移動・ダッシュ・ジャンプ・攻撃・必殺技を組み合わせられます。
