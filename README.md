# Repair Hero

フェニちゃんを操作して「スマホ修理商店街」を走り抜ける、オリジナルの 2D 横スクロールアクションゲームです。Canvas と `requestAnimationFrame` のみで動作し、ビルドや外部ライブラリは必要ありません。

## 遊び方

```sh
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開き、タイトル画面の「ゲームスタート」を選んでください。

| 操作 | キーボード | タッチ |
|---|---|---|
| 左移動 | `A` / `←` | 左下 `◀` |
| 右移動 | `D` / `→` | 左下 `▶` |
| ジャンプ／二段ジャンプ | `Space` | 右下中央 `JUMP` |
| 左右ダッシュ | `Shift`＋進行方向 | 左下・移動ボタンの真上 `DASH ←` / `DASH →` |
| 水中／KING上下移動 | `W` / `↑`、`S` / `↓` | 左下 `↑` / `↓`（該当時のみ表示） |
| 剣／ラッシュパンチ | `X` | 右下 `ATTACK` / `RUSH PUNCH` |
| ポーズ | `Escape` | 右上 `Ⅱ` |

## ステージ 1-1〜1-8

既存の「スマホ修理商店街」を 1-1 として残し、地下ケーブル迷宮、クラウド空中回廊、キング基板・決戦、本格地下迷宮、深海リペア海域、迫る圧壊壁へ連続して進みます。1-5 の最奥には HP ゲージ付きの大型ボス「MEGA BUG」が待っています。

### 1-1「スマホ修理商店街」

- 穴、段差、固定足場、3 基の移動足場を備えた全長 7,600px のステージ
- 遠景ビルと修理店街の 2 層パララックス背景
- スマホ戦闘ロボ、工具メカ、暴走バッテリーロボなど、ステージテーマ別のメカ敵
- 敵を上から踏むと撃破、横から接触または水滴に当たると 1 ダメージ
- HP 3、ダメージ後の無敵時間、コイン、スコア、制限時間
- 中間チェックポイント、落下復帰、ゲームオーバー、ゴール、クリア、リトライ、タイトル復帰

フェニちゃんは専用画像で描画され、速度に連動した上下動・前傾・砂煙で走行を表現します。ダッシュには残像と画面揺れ、二段ジャンプには回転・火花・専用効果音、着地には砂煙と軽い画面揺れが入ります。

## 4 種類の変身モード

安全な空中地点へ浮遊するモード別アイテムを取ると変身します。バッテリーは 25 秒間、被ダメージとノックバックを軽減し、被弾後に HP を徐々に回復します。液晶は 25 秒間、通常の約 1.42 倍で移動し、2 枚の青いシールドが最初の 2 回のダメージを無効化します。キングは 20 秒間、上下左右へ高速飛行できる完全無敵状態となり、通常敵を接触撃破し、ボスへ接触ダメージを与えます。ゴリマッチョは 25 秒間 `RUSH PUNCH` が使用可能です。

## 動作仕様

ゲームループはページにつき 1 本だけ生成され、移動や物理演算は delta time ベースです。液晶モードでも敵・BGM・タイマーは通常速度のままで、高速移動は細分化した衝突判定を通ります。リトライ時はプレイヤー、敵、弾、コイン、足場、チェックポイント、時間、カメラをすべて初期化します。Canvas は `resize`、`orientationchange`、`visualViewport`、縦横画面、最大 2 倍の `devicePixelRatio` に対応しています。縦画面では CSS 縮小ではなく実際のカメラ viewport を広げ、先読み範囲を確保します。タッチボタンは Pointer Events を利用し、ダッシュとジャンプを含む複数指の同時押しに対応します。

## SECTION 制ステージと決戦

全ステージは SECTION A〜E の攻略単位に再設計されています。警告ストライプ付きの穴、小足場、横・縦移動足場、時間制限床、落下物、敵弾、トゲ／電撃を組み合わせ、各 SECTION の直後には安全床上のチェックポイントがあります。背景、安全床、危険物はそれぞれ低彩度色、黄縁の床、赤／黄の発光色で識別できます。

1-5 の最終 SECTION は「MEGA BUG TITAN」とのボス戦です。手前のフェニックス剣（`phoenix_sword.png`）を取得すると `X` または右側の `⚔ ATTACK` で斬れます。ボスの頭へ上から着地してもダメージを与えられます。ゴリマッチョ中の `RUSH PUNCH` は横パンチ画像、連続拳残像、炎・火花・稲妻・画面シェイク・ヒットストップと、画面幅約 72% の貫通衝撃波を組み合わせ、遠距離の敵・壊せる壁・ボスへ命中します。ボスは HP 半分以下で高速な第2形態へ移行し、撃破演出が完了するまでゴールはロックされます。

1-6「地下迷宮」は深度の異なる長大な区画、縦移動足場、壊せる壁、危険物、分岐足場、隠し報酬を組み合わせた探索ステージです。1-7「深海リペア海域」は上下左右へ泳ぐ専用物理、水流、狭い洞窟、泡による酸素回復、OXYGEN ゲージを備えます。海中では `JUMP` が上昇、専用の `↓` が潜水になり、左右ダッシュも使用できます。両ステージに複数のチェックポイントがあり、海中での復帰時は酸素も全回復します。

1-8「圧壊ウォール・エスケープ」は後方の巨大壁が序盤・中盤・終盤で段階的に加速する強制スクロールステージです。壁が主な脅威になるよう通常トラップは抑え、ダッシュで破壊できる障害物と明確な走行ラインを中心に構成しています。

縦画面では主人公を画面高のおよそ16.5%に保ち、進行方向とジャンプ方向を先読みする専用カメラを使用します。高速移動時は先読み量を増やし、ボス戦では主人公とボスが同時に収まるよう実 viewport を自動調整します。ボス HUD と移動／左右ダッシュ／ジャンプ／攻撃は重ならない2列操作として表示します。Pointer Events による複数指入力のため、移動・ダッシュ・ジャンプ・攻撃を組み合わせられます。

## 検証

```sh
node --check game.js
node --check sound.js
node tests/smoke.test.js
```

回帰テストは全 8 ステージの安全スポーン、左右移動・ダッシュ・二段ジャンプ、水中移動、4 モード、LCD シールド、KING 飛行／接触撃破、ラッシュパンチ、剣、破壊壁と固定壁、チェックポイント、ボスゴールロック、迫る壁、画像参照、BGM／SE 初期化を確認します。さらに iPhone・iPad・Android 相当の縦横 viewport と PC viewport で、カメラ初期化・描画・安全配置を検証します。
