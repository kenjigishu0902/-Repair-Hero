# Repair Rush

スマートフォン修理をテーマにした、タッチ操作専用の2Dアーケードアクションゲームです。

## Play

`index.html` をブラウザで開くか、GitHub Pagesで公開してください。ビルドや外部ライブラリは不要です。

## Controls

- タップ: 受付、コネクタ解除、動作確認
- ドラッグ: ネジ外し、吸盤、ヘラ、部品交換、組み立て
- 長押し: Repair Burst（ゲージMAX時）

## Local preview

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
