# Images

Repair Hero はリポジトリ内の既存キャラクター画像を読み込み、背景・敵・攻撃エフェクトを Canvas 2D でリアルタイム描画します。

- 通常フェニちゃん: `feni.png`
- BATTERY MODE: `feni_battery.png`
- LCD MODE: `feni_lcd.png`
- KING MODE: `feni_king.png`
- GORI MACHO MODE: `fenichan_gorimacho.png`
- GORI MACHO 横パンチ: `fenichan_gorimacho_punch.png`
- フェニックス剣: `phoenix_sword.png`

画像ファイルは実在するパスだけを参照し、拳残像・炎・火花・稲妻・衝撃波などの動的エフェクトは Canvas で重ねて描画します。
